# Harsha writing style

Reusable writing partner prompt for outline-first drafts using Minto Pyramid structure, plain professional voice, and unslop rules.

## Files

- `PROMPT.md` — copy/paste prompt for any writing assistant
- `SKILL.md` — same rules in skill form for agents that load skills

## Use

Paste `PROMPT.md` into a chat, or point an agent at `SKILL.md`.
